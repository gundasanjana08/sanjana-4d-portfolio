Cybersecurity • Multi-Agent Systems

Building Cyber Defence as a Team of Agents

Traditional security tools often work as isolated detectors. A multi-agent cyber defence system explores a different model: specialist agents observe local behaviour, communicate evidence and coordinate a response through a central layer. The value is not just automation. It is context sharing. Each agent contributes a different signal, while the coordinator converts fragmented observations into a consistent action. My project explores threat detection, collaborative defence, dynamic policies and scalable monitoring using a TypeScript-based interface.

ServiceNow • Enterprise Platforms

What Enterprise Dashboards Should Actually Measure

A dashboard should not only show activity. It should show whether the organization is becoming more effective. For a ServiceNow adoption dashboard, meaningful indicators include self-service adoption, MTTR improvement, SLA compliance, license utilization and workflow automation. These measures connect platform usage to customer and business value. My ServiceNow Impact dashboard project was designed around that principle: visibility should lead to action.

Cybersecurity • Blockchain

Why Blockchain Can Strengthen Security Evidence

Security investigations depend on trustworthy records. If logs can be modified without detection, the evidence chain becomes weaker. Blockchain is not necessary for every logging system, but its immutability and distributed verification model can be useful when audit integrity is a primary requirement. In my portfolio, I explored blockchain-backed audit logging, phishing evidence and secure data sharing as ways to strengthen traceability and trust.

AI • Responsible Automation

AI Automation Should Keep Humans in Control

The best automation does not remove judgment blindly. It removes repetitive effort while making the decision process clearer. In workflow automation, conversational support and risk analysis, AI should surface context, explain recommendations and allow human review before high-impact actions. That human-centered approach is the direction I want to continue exploring through my AI and enterprise projects.

Real-Time Phishing Detection Needs More Than a Model

A phishing detector is not only a machine-learning model. A usable system also needs fast APIs, reliable feature extraction, evidence storage, explainable results and integration points for other platforms. My phishing detection concept combines Golang services, machine learning analysis, REST endpoints, Docker deployment and blockchain-backed records to explore the full system rather than only the prediction layer.
